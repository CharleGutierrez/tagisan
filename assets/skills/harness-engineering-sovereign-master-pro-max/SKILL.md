## 2. Master Operational Invariants (The 7 Pillars of Invariance)

1. **Zero-Exit-Code Masking**: No harness or pipeline node may swallow an error or exit 0 on partial failure.
2. **Deterministic Schema Strictness**: All structured communication must adhere to typed JSON envelopes or validated binary layouts.
3. **Hermetic Execution Safety**: Untrusted code must execute within Landlock/Seccomp/Seatbelt/AppContainer sandboxes with zero root escape potential.
4. **Interactive PTY Non-Blocking Guarantee**: PTY sessions must never hang on child processes; timeout escalation must be deterministic and infallible.
5. **Round-Trip Serialization Fidelity**: For all wire protocols and database schemas, `decode(encode(x)) == x`.
6. **Reproducible Counterexamples**: All fuzzing and property test failures must produce shrunk, deterministic inputs with logged seeds.
7. **Autonomous Self-Refinement**: Systems must continuously improve their own skill definitions and error guidance based on empirical execution telemetry.

## 3. End-to-End Autonomous Orchestration Playbook

When given a mission to build or integrate an external system:
1. **Analyze Interface**: Dispatch `harness-ast-abi-ingest-pro-max` or `harness-protocol-serialization-pro-max` to extract the full ABI and schema.
2. **Select & Generate Target**: Dispatch `harness-polyglot-cli-generator-pro-max` to compile a standalone native CLI with `--json` support.
3. **Enforce Isolation**: Wrap the execution in `harness-sandbox-pty-runtime-pro-max` with Landlock/Seccomp rules and PTY virtual screen buffers.
4. **Stress & Validate**: Dispatch `harness-fuzz-benchmark-pro-max` to generate 10,000+ property test runs and profile p99 latency.
5. **Compose & Wire**: Dispatch `harness-dag-lifecycle-telemetry-pro-max` to link the new harness into production DAG pipelines.
6. **Monitor & Self-Heal**: Ingest execution telemetry to continuously refine prompt cheat sheets and eliminate recurring agent friction.
