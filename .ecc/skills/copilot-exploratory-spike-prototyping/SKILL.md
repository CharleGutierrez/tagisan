# copilot-exploratory-spike-prototyping
> Based on **Extreme Programming Explained: AI Pair Programming - Kent Beck** (Cluster 9)

## 1. Core Mathematical & Architectural Foundations / Formal Invariants

1. **Spike Protocol: Throwaway code written to explore unfamiliar APIs and answer specific technical unknowns.**
2. **Time-Boxing: Constrain spike experiments to maximum 2 hours.**
3. **NEVER merge spike code directly to production without refactoring and writing tests.**
4. **ALWAYS enforce schema compliance, deterministic typing, and cryptographic audit receipts in copilot-exploratory-spike-prototyping.**
5. **MANDATORY timeout guarantees (30s default) and episodic reflection logging on all copilot-exploratory-spike-prototyping actions.**

## 2. Concrete Agent Specification & Prompt Contract (Vibe Coder Protocol)

### Prompt Contract
Conduct rapid exploratory spikes against unfamiliar Graph or Copilot APIs, extracting key learnings into durable skills.
