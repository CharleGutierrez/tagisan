## Practical Protocols for Agents & Developers

### Protocol 1: The Cryptoeconomic Invariant Checklist
1. **Velocity Control**: Calculate token velocity $V = \frac{P \cdot Q}{M}$. Enforce explicit economic sinks (staking rewards, protocol buyback-and-burn, governance utility) so the token is not a pure pass-through medium.
2. **AMM Pool Integrity**: Validate constant-product formula $x \cdot y = k$ after subtracting LP swap fees ($x_{new} = x + \Delta x \cdot (1 - \gamma)$).
3. **Oracle Resistance**: Audit price consumer contracts for TWAP (Time-Weighted Average Price) or Chainlink decentralized oracle usage; strictly reject instant reserve ratio checks.

### Protocol 2: The Smart Contract Audit & Exploit Prevention Gate
1. **Checks-Effects-Interactions**: Zero external token transfers or arbitrary calls before updating storage balances.
2. **Re-entrancy Guards**: Apply OpenZeppelin `ReentrancyGuard` to all non-view external entry points.
3. **Automated Fuzzing**: Configure property-based invariants in Foundry:
   ```solidity
   function invariant_totalReservesEqualSupply() public {
       assertEq(token.totalSupply(), pool.totalDeposited());
   }
   ```
4. **Integer Overflow & Precision**: Verify fixed-point arithmetic order of operations: multiply before dividing to preserve precision and prevent truncation down to zero.
